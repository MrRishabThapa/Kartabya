Google OAuth Tester

Kartabya backend · server-side redirect flow (Authlib + FastAPI)

Sign in with Google checking backend…

  1. Click Sign in with Google. The browser hits GET http://localhost:8000/auth/google, which redirects you to Google's consent screen (Authlib stores PKCE/state in the temporary kartabya_oauth_state cookie).
  2. After you approve, Google sends you back to /auth/google/callback. The backend validates state + nonce, exchanges the auth code for a token, and fetches your verified profile.
  3. The profile is printed to the backend terminal as [google-auth] Verified Google user (not persisted) JSON — that is where you confirm the sign-in worked. Nothing is saved to a DB or session yet.
  4. Finally the backend issues a 303 redirect to http://localhost:3000 (your FRONTEND_URL). Start the Next.js frontend to land there, or just watch the URL bar / DevTools Network tab to confirm the redirect happened.
Where do I see the result? In the terminal running uv run uvicorn app.main:app --reload. After the consent screen, watch for the printed JSON profile (email, name, picture, sub). If the flow fails, the callback returns a 400 JSON error in the browser instead — check that .env has valid GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET / SESSION_SECRET_KEY values and that http://localhost:8000/auth/google/callback is an authorized redirect URI in Google Cloud Console.
